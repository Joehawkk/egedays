# egedays - Обратный отсчёт до ЕГЭ 2026

Таймер до всех экзаменов ЕГЭ 2026 года. Обновляется ежесекундно.

🔗 **[Открыть сайт](https://joehawkk.github.io/egedays/)**

## Возможности

- Все предметы ЕГЭ
- Фильтр предметов - смотри только свои экзамены
- Часовой пояс - от Калининграда до Камчатки
- Прогресс-бар - сколько времени прошло с 1 сентября
- Мотивационные цитаты, меняются каждые 15 минут
- Адаптирован под любые устройства

## Экзамены

| Предмет | Дата |
|---|---|
| История, Литература, Химия | 1 июня |
| Русский язык | 4 июня |
| Математика (баз.), Математика (проф.) | 8 июня |
| Обществознание, Физика | 11 июня |
| Биология, География, Ин. языки (письм.) | 15 июня |
| Информатика | 18 июня |
| Ин. языки (устн.) | 19 июня |

## Стек

Чистый HTML, CSS, JavaScript - без зависимостей и сборки.
