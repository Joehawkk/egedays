# egedays — Сайт, показывающий, сколько осталось до ЕГЭ 2026.

Обратный отсчёт до четырёх экзаменов ЕГЭ 2026 года. Обновляется ежесекундно.

🔗 **[Открыть сайт](https://joehawkk.github.io/egedays/)**

## Экзамены

| Предмет | Дата |
|---|---|
| Русский язык | 4 июня, 10:00 |
| Профильная математика | 8 июня, 10:00 |
| Физика | 11 июня, 10:00 |
| Информатика | 18 июня, 10:00 |

## Возможности

- Таймер обновляется каждую секунду
- Прогресс-бар — показывает сколько времени прошло с 1 сентября
- Адаптирован под любые устройства
- Приятный тёмный интерфейс с эффектом стекла на карточках

## Стек

Чистый HTML, CSS, JavaScript — без зависимостей и сборки.

## Запуск локально

```bash
git clone https://github.com/Joehawkk/egedays.git
cd egedays
open index.html
```
